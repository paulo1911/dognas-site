Follow everything

Privacy and control

Your files stay with you

DogNAS has no cloud: access happens between your own devices, on your network.

Your storage

Files stay in the storage you chose on the server device: internal memory, an SD card or a USB drive.

Encrypted connection

Access uses SFTP over SSH-2 and the server is pinned when you pair. It is meant for the same Wi-Fi network; access from outside your home is not part of the product today.

One PIN per profile

Each profile has its own PIN and folders, and each paired device has a credential you can revoke at any time.

Apps that collect nothing

The apps do not collect, send or sell personal data and have no ads. This website uses Google Analytics only if you accept.

Your files stay in the storage set up on your server device. Access depends on your network setup and your DogNAS credentials. For important files, keep an independent backup copy.

Compatibility

Requirements and limits

Android 7.0 or newer

On the server and on the client phones, all on the same Wi-Fi network.

USB drives

Need USB OTG on the server phone. Spinning hard drives may need more power than the phone provides: use a powered USB hub.

Server in the foreground

The server runs as a foreground service with a persistent notification and stays active with the screen off and the app closed. Even so, Android and some makers may stop it to save battery: if you notice interruptions, adjust battery saving and DogNAS permissions.

Storage is not a backup

A single disk can fail. Keep an independent copy of important files.

Frequently asked questions

Do I need to buy a new device?

Not necessarily: you can reuse a compatible Android (Android 7.0 or newer). See the requirements above. Read the guide: How to turn an old Android into a file server

Does it work on a tablet?

Yes. DogNAS runs on any compatible Android, phone or tablet: a tablet sitting at home can be the server, and your other devices reach it over Wi-Fi. The apps’ screens are still designed for phones, but they work on larger screens. Read the guide: Old tablet sitting idle? Turn it into home storage

Do I need internet?

To use it at home you only need the Wi-Fi network that connects your devices; you need internet to install the apps. Access from outside your home is not part of the product today. Read the guide: How to transfer files between your PC and phone over Wi-Fi, no cable

Does DogNAS send my files to the cloud?

No. Files stay in the server device’s storage and travel between your devices, on your network. The apps collect no personal data; this website uses Google Analytics only if you accept.

Can I use an external drive?

Yes, with a phone that has USB OTG and a drive Android recognizes. Spinning hard drives may need a powered USB hub. Each drive is an independent storage. Read the guide: How to reuse an old laptop's hard drive as home storage

Does the server keep running with the screen off or the app closed?

Yes, on any plan: the server runs as a foreground service with a persistent notification (and a Stop button), which keeps it active with the screen off and after you close the app. Android or the maker can still stop it to save battery: if you notice interruptions, adjust DogNAS permissions and battery saving.

Is the Free plan transfer pause a server behavior?

No. It is a client app behavior, not a server one. On the Free plan, uploads and downloads made by the client app pause when you leave the client app and resume when you return; on Pro they keep going in the background. The server keeps running in both cases.

Does this replace a backup?

No. A single disk or phone can fail. Keep an independent copy of what matters.

Can I connect several servers?

Yes. Each DogNAS shows up as an independent destination under “My storages” in the client app.

Do several drives become one volume?

No. DogNAS does not combine drives into one volume (no RAID, no splitting files across drives): each drive or device is a separate storage.

How do I start?

Install DogNAS on the Android that will keep the files, tap Start, generate a profile’s QR Code and scan it with the client app. See the three steps above. Read the guide: A home NAS without buying a NAS: use the Android you already own
